============================================================
CUSTOM PLUG-AND-PLAY NAVIGATION ENGINE SYSTEM
============================================================

PROJECT GOAL:
Build a fully reusable, scalable, customizable, future-proof
Flutter navigation framework.

The system should work like a professional UI framework.

============================================================
MAIN IDEA
============================================================

Instead of making:
- one big navigation widget
- hardcoded values
- fixed styles

We will build:
- modular architecture
- config-driven system
- reusable design engine
- style presets
- animation engine
- indicator engine

============================================================
FINAL USAGE GOAL
============================================================

CustomBottomNav(

  items: navItems,

  currentIndex: currentIndex,

  layoutConfig: NavLayoutConfig(),

  styleConfig: NavStyleConfig(),

  itemConfig: NavItemConfig(),

  animationConfig: NavAnimationConfig(),

  utilityConfig: NavUtilityConfig(),

  onTap: (index) {},
)

============================================================
MAIN CONFIG MODELS
============================================================

------------------------------------------------------------
1. NavLayoutConfig
------------------------------------------------------------

Purpose:
Controls all layout and sizing behavior.

Parameters:

- double height
- double? width
- EdgeInsetsGeometry margin
- EdgeInsetsGeometry padding
- double borderRadius
- double iconSize
- double gap
- MainAxisAlignment alignment
- bool expandItemsEvenly
- bool floating

============================================================

------------------------------------------------------------
2. NavStyleConfig
------------------------------------------------------------

Purpose:
Controls all styling and visual effects.

Parameters:

- NavStyle style
- Color? backgroundColor
- Gradient? backgroundGradient
- bool useBlur
- double blurSigma
- bool enableGlow
- Color? glowColor
- List<BoxShadow>? shadows
- Border? border
- double opacity

============================================================

------------------------------------------------------------
3. NavItemConfig
------------------------------------------------------------

Purpose:
Controls item appearance and text behavior.

Parameters:

- Color? selectedColor
- Color? unselectedColor
- bool showLabels
- TextStyle? selectedLabelStyle
- TextStyle? unselectedLabelStyle
- double activeIconScale
- double inactiveIconScale
- bool useActiveIcon

============================================================

------------------------------------------------------------
4. NavAnimationConfig
------------------------------------------------------------

Purpose:
Controls animations and transitions.

Parameters:

- NavAnimation animation
- NavIndicator indicator
- Duration duration
- Curve curve
- bool enableFeedback
- bool enableScaleAnimation
- bool enableRotationAnimation
- bool enableFadeAnimation
- bool enableSlideAnimation

============================================================

------------------------------------------------------------
5. NavUtilityConfig
------------------------------------------------------------

Purpose:
Handles advanced utility behavior.

Parameters:

- bool useSafeArea
- double blurOpacity
- Clip clipBehavior
- bool adaptiveLayout
- bool repaintBoundaries
- bool lazyLoadScreens

============================================================

------------------------------------------------------------
6. NavItemModel
------------------------------------------------------------

Purpose:
Stores each navigation item's data.

Parameters:

- IconData icon
- IconData? activeIcon
- String label
- Widget screen
- int badgeCount
- bool showNotificationDot
- Widget? customWidget
- bool disabled

============================================================
ARCHITECTURE PRINCIPLES
============================================================

1. Never hardcode values.

2. Every feature should be configurable.

3. Separate:
   - logic
   - UI
   - animations
   - styles
   - layouts
   - indicators

4. Widgets should stay small and reusable.

5. All advanced effects should be optional.

6. Every system should support future expansion.
